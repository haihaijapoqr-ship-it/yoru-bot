🌙 Project: Yoru — The Anime Game Bot
🧩 Concept:

A Discord bot inspired by OwO, but built around:

Anime actions (kiss, hug, slap, etc.)

Cyber-fantasy RPG world

Custom leveling + economy system

Stylish neon aesthetics

🎮 1. Core Identity
Feature	Description
Theme	Futuristic anime world with cyber spirits & hackers
Main Loop	Social interaction → Currency & XP → Gear → Duels
Art Style	Neon colors, anime GIFs, glowing UI
Tone	Cute, clever, slightly mischievous 😼
💞 2. Anime Action System (OwO-style)
🔹 Core Idea:

Exactly like OwO’s owo kiss / owo slap, but more dynamic + cooler visuals.

🕹️ Commands:
Command	Example Output
yoru kiss @user	💞 @you kissed @user — “Sweet bytes of affection.”
yoru hug @user	🤗 @you hugged @user tight.
yoru slap @user	💢 @you slapped @user — “System reboot required!”
yoru pat @user	🩷 @you pats @user on the head softly~
yoru cuddle @user	💤 @you cuddles @user under a digital sky.
yoru blush	🥺 @you is overheating (blush.exe detected).
yoru bonk @user	🔨 @you bonks @user back to reality.
⚙️ Backend:

Uses nekos.best or waifu.pics API for random anime GIFs

Random caption generator for each command

Cooldown (2–5 seconds) to prevent spam

Optionally gives Emotion XP (for fun leveling)

⚔️ 3. Game System — Yoru’s World: The Hackverse
🧠 Concept:

You are a “Data Hunter”, exploring servers, fighting rogue AIs, and finding Yoru Fragments.

🎯 Commands:
Command	Description
yoru hack	Try to hack a node for rewards
yoru scan	Search for artifacts
yoru duel @user	Battle another player’s AI
yoru forge	Fuse weapons or upgrade tools
yoru daily	Claim your daily credits
yoru work	Earn credits via small jobs
yoru inventory	View your items
yoru profile	Check your stats & level
yoru rank	Show your rank among players
💰 Economy:
Currency	Symbol	Use
Credits	₿	Base money
Fragments	💠	Crafting materials
Energy	⚡	Needed for hacking missions
🧾 Example Game Output:
💻 Yoru Terminal:
Accessing Node 7B...
🔓 Hack Successful!
You gained +350₿ and found 1 Rare Fragment 💠

🛡️ 10. Cooldowns & Anti-Spam

!kiss, !hug → 5 sec cooldown

!hack → 10 sec cooldown

!duel → 30 sec cooldown

!daily → 24 hrs cooldown

Per-user cooldown stored in memory or MongoDB
