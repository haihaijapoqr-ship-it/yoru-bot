# 🌙 Yoru - Anime Game Discord Bot

Yoru is a feature-rich Discord bot that combines powerful moderation tools with an immersive anime-themed RPG game called "The Hackverse". Players can use cute anime interaction commands, hack nodes for rewards, collect legendary weapons, battle other players in duels, and progress through a cyberpunk-styled leveling system.

## ✨ Features

### 💞 Anime Actions (20+ Commands)
Interact with friends using adorable anime GIF reactions:
- **Affection**: `/kiss`, `/hug`, `/cuddle`, `/pat`, `/handhold`
- **Playful**: `/poke`, `/bonk`, `/bite`, `/lick`, `/yeet`
- **Expression**: `/blush`, `/smile`, `/wink`, `/wave`, `/cry`, `/happy`
- **Combat**: `/slap`, `/kick`
- **Fun**: `/highfive`, `/nom`, `/dance`

Each action rewards **Emotion XP** and displays random anime GIFs from free APIs!

### 🎮 The Hackverse - Game System

#### Currencies
- **Credits (₿)** - Buy weapons and items
- **Fragments (💠)** - Rare crafting materials
- **Energy (⚡)** - Required for hacking (max 10)

#### Game Commands
- `/hack` - Hack nodes for 150-400₿, fragments, and XP (costs 1⚡, 15s cooldown)
- `/scan` - Search for artifacts (unlocks at level 5, 20s cooldown)
- `/work` - Complete jobs for 80-180₿ and XP (30s cooldown)
- `/daily` - Claim daily rewards with streak bonuses (24hr cooldown)

#### ⚔️ Weapon System
10 weapons from Common to Mythic rarity:
- Common: Data Shard (2 ATK), Neon Dagger (3 ATK)
- Uncommon: Pulse Blade (5 ATK)
- Rare: Cyber Katana (8 ATK), Plasma Cutter (10 ATK)
- Epic: Shadow Edge (15 ATK), Phantom Blade (18 ATK)
- Legendary: Dragon Protocol (25 ATK), Yoru's Edge (30 ATK)
- Mythic: Void Ripper (40 ATK, 15 DEF)

**Commands**: `/shop`, `/buy`, `/inventory`, `/equip`, `/sell`, `/forge`

#### ⚔️ Duel System
- Challenge other players to turn-based combat
- Unlocks at level 10
- Winner earns 200-500₿ and 50-100 XP
- Uses equipped weapons and level bonuses
- 45-second cooldown

### 📊 Profile & Progression
- `/profile` - View your cyberpunk-styled profile with stats
- `/stats` - Detailed statistics breakdown
- `/leaderboard` - Global rankings (XP, credits, duels, hacks, level)
- `/rank` - Check your server rank and XP progress

Dual XP System:
- **Game XP** - From hacking, working, duels
- **Emotion XP** - From social interactions

### 🛡️ Moderation Tools
- `/ban` - Ban users
- `/kick` - Kick users
- `/warn` - Issue warnings

### ℹ️ Utility Commands
- `/ping` - Check bot latency

## 🚀 Setup Instructions

### 1. Prerequisites
- Python 3.11 or higher
- A Discord bot token ([Create one here](https://discord.com/developers/applications))

### 2. Installation on Replit

1. **Add your Discord Bot Token:**
   - Click on "Secrets" (🔒 icon) in the left sidebar
   - Add a new secret:
     - Key: `DISCORD_TOKEN`
     - Value: Your bot token from Discord Developer Portal

2. **Enable Discord Bot Intents:**
   - Go to [Discord Developer Portal](https://discord.com/developers/applications)
   - Select your application
   - Go to "Bot" section
   - Enable these Privileged Gateway Intents:
     - ✅ Presence Intent
     - ✅ Server Members Intent
     - ✅ Message Content Intent

3. **Run the Bot:**
   - Click the "Run" button
   - The bot will start automatically!

### 3. Invite the Bot to Your Server

Use this permission integer: `8` (Administrator) or customize with these permissions:
- Read Messages/View Channels
- Send Messages
- Embed Links
- Attach Files
- Read Message History
- Add Reactions
- Manage Messages
- Manage Roles
- Manage Channels
- Kick Members
- Ban Members
- Moderate Members (for timeout)

**Invite Link Template:**
```
https://discord.com/api/oauth2/authorize?client_id=YOUR_BOT_ID&permissions=8&scope=bot%20applications.commands
```

Replace `YOUR_BOT_ID` with your bot's Application ID.

### 4. Local Installation (Optional)

```bash
# Clone the repository
git clone <your-repo-url>
cd yoru-bot

# Install dependencies
pip install discord.py aiosqlite aiohttp python-dotenv

# Create .env file
cp .env.example .env
# Edit .env and add your DISCORD_TOKEN

# Run the bot
python bot.py
```

## 🎮 Gameplay Loop

1. Use `/daily` to get starter credits
2. Use `/work` or `/hack` to earn more credits
3. Browse `/shop` and `/buy` your first weapon
4. `/equip` your weapon for combat bonuses
5. Interact with friends using anime commands for Emotion XP
6. At level 10, challenge others with `/duel`
7. Climb the `/leaderboard` rankings!

## 🐛 Troubleshooting

**Bot doesn't respond:**
- Make sure you enabled all Privileged Intents in Discord Developer Portal
- Check that the bot has proper permissions in your server
- Verify your DISCORD_TOKEN is correct in Replit Secrets

**Commands not showing:**
- Wait a few minutes for Discord to sync slash commands
- Try kicking and re-inviting the bot with the correct scopes

**Database errors:**
- The `data/` directory is created automatically
- Database is initialized on first run
