# Yoru - Modular Discord Bot

Yoru is a feature-rich, modular Discord bot built with discord.py that supports moderation, logging, tickets, economy, leveling, reaction roles, and fun utilities.

## Features

### 🛡️ Moderation
- `/ban` - Ban users from the server
- `/unban` - Unban users
- `/kick` - Kick users
- `/warn` - Warn users with persistent warnings
- `/warnings` - View user warnings
- `/mute` - Timeout users with duration support (10m, 1h, 2d)
- `/clear` - Bulk delete messages

### 📋 Logging System
Configurable logging to different channels for:
- Member joins/leaves
- Bans/unbans
- Message edits/deletes
- Member updates (nickname, roles)
- Channel/role creation/deletion
- Moderation actions
- Ticket events

### 🎫 Ticket System
- `/ticket create` - Create support tickets
- `/ticket close` - Close tickets
- `/ticket setup` - Configure ticket system (admin)
- `/ticket addstaff` - Add staff roles

### 💰 Economy
- `/balance` - Check coin balance
- `/daily` - Claim daily rewards
- `/shop` - View available items
- `/buy` - Purchase items
- `/pay` - Send coins to other users

### 📊 Leveling
- Automatic XP on messages
- `/rank` - View your level and XP progress
- `/leaderboard` - View XP and economy leaderboards

### 🎮 Reaction Roles
- `/autoreact add` - Add reaction roles to messages
- `/autoreact remove` - Remove reaction roles

### 🎲 Fun Commands
- `/8ball` - Ask the magic 8-ball
- `/coinflip` - Flip a coin
- `/meme` - Get a random programming meme
- `/roll` - Roll a dice

### ℹ️ Utility
- `/ping` - Check bot latency
- `/help` - View all commands
- `/serverinfo` - Server information
- `/userinfo` - User information
- `/avatar` - View user avatars

### ⚙️ Configuration
- `/setlog` - Configure log channels
- `/logsettings` - View current log settings
- `/setprefix` - Set command prefix
- `/setmodrole` - Add moderation roles
- `/removemodrole` - Remove moderation roles

## Setup Instructions

### 1. Prerequisites
- Python 3.10 or higher
- A Discord bot token ([Create one here](https://discord.com/developers/applications))

### 2. Installation

1. Clone or download this repository

2. Install dependencies:
```bash
pip install discord.py aiosqlite python-dotenv
```

3. Create a `.env` file in the root directory:
```
DISCORD_TOKEN=your_bot_token_here
```

4. Run the bot:
```bash
python bot.py
```

### 3. Bot Permissions

When inviting the bot to your server, make sure it has these permissions:
- Read Messages/View Channels
- Send Messages
- Embed Links
- Attach Files
- Read Message History
- Add Reactions
- Manage Messages
- Manage Roles
- Manage Channels
- Kick Members
- Ban Members
- Moderate Members (for timeout)

### 4. Initial Configuration

After inviting the bot:

1. **Set up logging:**
   ```
   /setlog join #logs-channel
   /setlog moderation #mod-logs
   ```

2. **Configure moderation roles:**
   ```
   /setmodrole @Moderator
   ```

3. **Set up tickets (optional):**
   ```
   /ticket setup category:#tickets staff_role:@Support
   ```

4. **Configure economy settings** - Default settings work out of the box!

## Project Structure

```
yoru-bot/
├── bot.py                 # Main bot entry point
├── cogs/                  # Modular command groups
│   ├── core.py           # Basic commands (ping, help, info)
│   ├── config.py         # Configuration commands
│   ├── logs.py           # Event logging system
│   ├── moderation.py     # Moderation commands
│   ├── tickets.py        # Ticket system
│   ├── economy.py        # Economy system
│   ├── leveling.py       # XP and leveling
│   ├── reaction_roles.py # Reaction role handler
│   └── fun.py            # Fun commands
├── db/
│   └── models.py         # Database schema and operations
├── utils/
│   ├── embeds.py         # Embed templates
│   ├── checks.py         # Permission checks
│   └── cache.py          # Caching utilities
├── data/
│   ├── yoru.db           # SQLite database (auto-created)
│   └── backups/          # Backup storage
└── .env                  # Environment variables (you create this)
```

## Database Schema

The bot uses SQLite for data persistence with these tables:
- `guild_configs` - Per-server configuration
- `moderation_logs` - Moderation action history
- `warnings` - User warnings
- `economy` - User balances and inventory
- `leveling` - User XP and levels

## Customization

### Economy Settings
Edit the default values in your guild config or modify `cogs/economy.py`:
- Currency name
- Daily reward amount
- Shop items

### Leveling System
Modify XP gain and level calculations in `cogs/leveling.py`:
- XP per message (currently 15-25)
- Cooldown between XP gains (currently 60 seconds)
- Level calculation formula

### Fun Commands
Add more responses in `cogs/fun.py`:
- 8-ball responses
- Memes
- Custom fun commands

## Troubleshooting

**Bot doesn't respond to commands:**
- Make sure the bot has the "applications.commands" scope
- Check that command tree is synced (happens automatically on startup)
- Verify bot permissions in the server

**Database errors:**
- Ensure the `data/` directory exists
- Check file permissions

**Missing intents error:**
- Enable all privileged intents in Discord Developer Portal
